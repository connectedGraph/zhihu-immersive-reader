# 📜 知乎沉浸阅读脚本


[![Install](https://img.shields.io/badge/安装-最新版本-brightgreen.svg)](https://greasyfork.org/zh-CN/scripts/573678)
> 把知乎从信息流平台，重新变成一个适合深度阅读、认知提升、外语学习与表达积累的工具。

知乎沉浸阅读脚本是一款面向知乎重度阅读者的用户脚本。它会把复杂、拥挤、不断分心的知乎页面，转换成更安静的卷轴式阅读环境：多主题护眼、去广告、保留必要互动、支持打印导出，并集成 AI 翻译、摘要、划词解析、表达收藏本与首页信息流 Wiki。

当前最新版已不再只服务专栏文章：它已经支持 **知乎首页推荐流、/question 问题页、单个回答页、zhuanlan 专栏文章页**。

仓库地址：[connectedGraph/zhihu-immersive-reader](https://github.com/connectedGraph/zhihu-immersive-reader)

## 🚀 最新版 v1.17.0

**表达收藏本 + 问题页懒加载 + 首页 Wiki Beta**

这一版的方向很明确：不只是“净化页面”，而是把知乎阅读整理成一条学习流水线。

- 🧠 **首页信息流 Wiki Beta**：把首页推荐采集成学习卡片库，自动抓取正文、生成结构化知识卡片、可选今日总览，并导出 Markdown。
- 🪶 **表达收藏本**：划词即可收藏表达，保存原文段落、译文段落、来源链接、AI 批注，支持 Markdown / JSON 导出。
- 🔎 **AI 划词解析**：选中文字后右键，基于当前段落快速解释词句。
- 🌍 **上下文感知翻译**：先生成 AI 全文概括，再逐段翻译；最新版已将系统规则、全文概括、当前段落拆成独立 messages，减少误译与复述。
- ⚡ **问题页懒加载**：/question 页面初次只采集首批回答，后续滚动或点击再加载，启动更快。
- 🏠 **首页推荐懒加载**：首页推荐流按批加载，可在沉浸模式中用 `J` / `K` 切换。
- 🛠️ **交互优化**：回答/推荐正文页的导航条缩小并放到右上角，标题重新成为视觉中心。
- 🧯 **评论区头像修复**：修复首页推荐文章评论输入框展开时头像被竖向拉伸的问题。
- 🎨 **多主题护眼**：宣纸、竹简、牛皮、暗血、简白、日晒、极光、醇沙、德古拉、极客白、极客暗等主题。
- 🧹 **去广告与打印优化**：自动隐藏侧边栏、推荐卡片、购物卡片、部分引流广告，并优化 PDF 打印边距与分页。

> Wiki 当前仍是 Beta：它已经能跑完整工作流，但还没有做大量性能、交互和异常体验优化。

## ✨ 核心能力

### 📖 沉浸式阅读

- 一键展卷，把知乎内容放进更安静的阅读容器。
- 隐藏顶部栏、侧边栏、推荐流、引流广告和大部分视觉噪音。
- 保留必要的原生互动区域，例如点赞、收藏、评论输入等。
- 支持图片折叠，长文阅读时减少视觉打断。
- 支持浏览器打印/PDF 导出，尽量避免图片、表格、代码块被分页切断。

### 🎨 多主题

内置多种阅读主题，适合不同环境光线和阅读情绪：

- 📜 宣纸
- 🎋 竹简
- 🧳 牛皮
- 🧛 暗血
- ⚪ 简白

### 🌍 AI 翻译与摘要

- 支持 OpenAI 兼容格式 API。
- 可配置 API Host、API Key、模型名称和目标翻译语言。
- 支持将目标语言写成普通语言名，也可写成自定义提示词，例如“英文”“文言文”“现代汉语解释”。
- 可生成全文摘要，用作后续段落翻译上下文。
- 段落翻译保留表格 HTML 结构，公式块和代码块尽量原文保留。
- 翻译结果和全文摘要会写入本地缓存，减少重复请求。

### 🪶 表达收藏本

适合外语学习、写作积累、术语沉淀和金句摘录。

- 沉浸模式下划词右键，选择“加入表达本”。
- 保存选中词句、原文段落、译文段落、来源标题、来源链接、收藏时间。
- 可手写批注，也可让 AI 自动生成释义与语境分析。
- 自动去重：同一页面、同一表达、同一上下文重复收藏时，会更新到最新条目。
- 支持复制 Markdown、下载 Markdown、下载 JSON。

### 🔎 AI 划词解析

选中文字后右键选择“AI 划词解析”，脚本会把当前段落和选中内容一起发给模型，生成不超过 100 字的中文解释。适合快速理解术语、梗、复杂句、隐含语气和专业表达。

### 🧠 首页信息流 Wiki Beta

这是最新版里最实验、也最有野心的功能：把首页推荐流变成个人学习卡片库。

工作流：

1. 在知乎首页进入沉浸模式。
2. 点击 `W` 打开信息流 Wiki 面板。
3. 脚本采集首页推荐条目。
4. 尝试抓取每条内容的完整正文。
5. 按回答、问题、文章等类型整理输入。
6. 调用 AI 生成严格 JSON 学习卡片。
7. 可选生成今日总览。
8. 输出 Markdown，可复制或下载。
9. 本地保存 Wiki 运行历史。

学习卡片会包含：

- 内容类型
- 一句话结论
- 核心知识点
- 可迁移场景
- 证据与例子
- 入库判断
- 检索标签
- 可信度与原因

它的目标不是做新闻摘要，而是把信息流中真正有复习价值、可迁移价值的内容沉淀下来。

## ⚙️ 配置项

设置面板支持以下参数：

- `apiHost`：OpenAI 兼容接口地址，默认 `https://api.deepseek.com/v1`。
- `apiModel`：模型名称，默认 `deepseek-chat`。
- `apiKey`：API Key，仅保存于浏览器本地。
- `targetLang`：目标翻译语言或翻译提示词。
- `autoSum`：展卷时自动生成全文摘要。
- `autoTr`：展卷时自动异步翻译全文，耗量较大。
- `autoHideImages`：展卷时自动折叠正文图片。
- `answerPreviewMode`：回答列表预览模式，可选摘录前文或 AI 摘要。
- `wikiMaxItems`：Wiki 单次最大采集条数。
- `wikiConcurrency`：Wiki 抓取与 AI 摘要并发数。
- `wikiRpm`：Wiki AI 请求 RPM 限速。
- `wikiFinalSynthesis`：是否生成今日总览。

## 💾 本地存储与隐私

脚本的数据都保存在本地浏览器中，没有云同步，也不会上传到脚本作者服务器。

主要本地数据：

- `zh-immersive-config`：API 与功能配置。
- `zh-immersive-translation-cache-v1`：翻译和摘要缓存。
- `zh-immersive-expression-book-v1`：表达收藏本。
- `zh-immersive-wiki-history`：Wiki 运行历史。
- IndexedDB `zh-immersive-question-cache/questionAnswers`：问题回答列表缓存。

注意：如果你填写了 API Key，它会保存在浏览器 `localStorage` 中。请只在自己信任的浏览器环境使用。

## 🧭 推荐工作流

### 🌊 把首页推荐变成学习素材池

打开知乎首页，进入沉浸模式，点击 `W` 运行 Wiki。让脚本从信息流里抓取内容、筛选价值、生成卡片。每天跑一次，就像给自己的知识库补充一批候选素材。

### 🧑‍🏫 把回答页变成深度阅读队列

进入 `/question` 页面后展卷。首屏只采集少量回答，启动更快。读完当前批次后滚动到底或点击按钮继续加载，避免一开始就把整页回答全部拖进来。

### 🌍 把中文语境变成外语学习跳板

知乎天然有大量中文母语语境。你可以把目标语言设成英文或其它语言，通过“原文 + 译文 + 划词解析 + 表达收藏本”积累更具语境感的表达。

### 🪶 把好句子沉淀成表达库

遇到漂亮句子、术语、比喻、论证结构时，直接划词加入表达本。导出的 Markdown 可以放进 Obsidian、Notion 或其它笔记工具。

### 🖨️ 把长文变成干净 PDF

进入沉浸模式后直接使用浏览器打印。脚本会尽量隐藏站点 UI，并优化图片、表格、代码块和分页。

## ⚠️ 已知限制

- Wiki 仍是 Beta，可能遇到抓取失败、卡片回退、部分页面结构识别不准等问题。
- AI 功能需要 OpenAI 兼容格式 API；Claude、Gemini 原生接口需要中转或兼容层。
- API Key、缓存、表达本、Wiki 历史均为本地浏览器存储，不跨设备同步。
- 首页推荐和问题页结构会随知乎前端更新变化，若知乎改版，选择器可能需要维护。
- 自动全文翻译和 Wiki 批量摘要会消耗较多 API 额度，请按需开启。

## 💡 开发动机

这个脚本最初只是为了让知乎长文读起来舒服一点。后来它逐渐长出了翻译、摘要、回答导航、首页推荐流、表达收藏本和 Wiki。

它现在更像一个小型阅读工作台：去掉干扰，保留上下文，把文章、回答和信息流重新组织成可以学习、可以复习、可以导出的东西。

如果说知乎原本是一个不断刷新、不断滑走的信息流，那么这个脚本想做的事情就是：把它重新变成一卷可以慢慢读、反复读、带走读的纸。
